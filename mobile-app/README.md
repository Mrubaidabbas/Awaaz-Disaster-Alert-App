# Awaaz mobile app prototype

This is the phone app version of the Awaaz class prototype, built with Expo and React Native.

## Preview it on Android

1. Install Node.js 22.13 or newer on your computer.
2. Install **Expo Go** from the Play Store on your Android phone.
3. Open a terminal in this `mobile-app` folder and run `npm install` once.
4. Run `npx expo start`.
5. Connect your phone and computer to the same Wi-Fi, then scan the QR code using Expo Go.

The first preview needs internet access to download project packages. Keep the terminal running while you use the app.

## Demo scope

The screen supports simulated flood, cloudburst, earthquake, wildfire and house-fire alerts, sample-area station routing, and station receipt acknowledgement. It does not include a trained AI model, live sensors, real GPS routing, SMS, station integrations, siren controls, or real emergency notifications. Do not use it for emergency response.
