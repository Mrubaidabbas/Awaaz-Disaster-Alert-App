# Awaaz app source

This clean package contains the Awaaz browser prototype and the Android/iPhone mobile app source. It does not contain assignment instructions, assignment reports, or proposal documents.

## Open the browser prototype

Open `web-app/index.html` in Chrome or another modern browser. The browser demo runs locally and needs no install.

## Preview the mobile app on Android

1. Install Node.js 22.13 or newer on the computer.
2. Install Expo Go from the Google Play Store on the Android phone.
3. Connect the computer and phone to the same Wi-Fi.
4. Open the `mobile-app` folder and double-click `START_MOBILE.bat`.
5. The first run downloads the app packages. When Expo shows a QR code, scan it with Expo Go.

If Windows displays a security prompt for the batch file, choose **Run**. Keep the terminal window open while testing. Press Ctrl+C to stop Expo.

## limits

Both apps use sample data. No AI model, sensors, live GPS, SMS, external station connection, public alert, or siren is connected. Do not use this prototype for emergency response.
